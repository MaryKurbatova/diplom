## СБОРКИ

Профессиональное веб-приложение для автоматизации производственного учёта и управления жизненным циклом телекоммуникационного оборудования, разработанное для АО «НПП «Исток» им. Шокина».

## ФУНКЦИОНАЛ

## Учёт производства
- **Устройства:** регистрация, редактирование, удаление сервисных маршрутизаторов (RS) и коммутаторов доступа (SA)
- **Платы:** учёт печатных плат с привязкой к устройствам
- **Корпуса:** учёт корпусов с автоматическим определением типа (RS/SA)
- **Сотрудники:** управление персоналом с ролевой моделью доступа

## Производственные стенды
- **Визуальный осмотр:** проверка качества пайки и компонентов плат
- **Диагностика:** тестирование портов, ОС, дисков и памяти
- **Сборка:** монтаж платы в корпус с автогенерацией серийного номера
- **ПСИ (Приёмо-сдаточные испытания):** финальное тестирование с протоколом
- **Упаковка:** генерация PDF-наклеек с QR-кодами для коробки и паспорта

## Раздел «Ремонт»
- Автоматическая фильтрация бракованных объектов
- Возобновление проверки с возвратом на соответствующий стенд
- Удаление записей (только для администратора)

## Аналитика и отчётность
- Дашборд с ключевыми метриками производства
- Распределение по типам, стадиям и местам производства
- Таблица последних операций
- Интерактивные горизонтальные диаграммы с анимацией

## Управление доступом
- **Администратор:** полный доступ ко всем функциям
- **Технолог (user):** редактирование без удаления
- **Оператор:** только прохождение стендов

## УСТАНОВКА И ЗАПУСК

## Требования
- Node.js 18.x или новее
- MySQL 8.0 или новее
- npm 9+
- Браузер Chrome/Firefox/Edge (последняя версия)

## Быстрый старт
- Установите зависимости проекта командой: `npm install`
- Создайте базу данных `istok` и импортируйте в неё данные из файла `database.sql`
- Проверьте настройки подключения к БД в файле `server.js`
- Запустите сервер командой: `npm start` (или `npm run dev` для режима разработки)
- Откройте приложение в браузере по адресу: `http://localhost:3000`
